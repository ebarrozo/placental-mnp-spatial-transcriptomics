# Supplementary Table 1 workflow

`Supplementary_Table_1_MNP_spatial_analysis_outputs.xlsx` is generated by `scripts/11_build_supplementary_table1.R`.

The archived working script, `provenance/archived_scripts/supp_table1.R`, was originally run after `meta_update.R` and collected objects/files from the active R session. The public workflow is deliberately stricter: it reads source CSV/TSV files generated by the modular repository scripts and writes one workbook plus matched CSV source tables under `outputs/tables/supplementary_table1/`.

## Public-data / PHI note

The metadata sheet is built using a conservative allowlist. Direct identifiers, exact dates, free-text clinical fields, addresses, MRNs, and other PHI-like columns should remain excluded from the public workbook. This mirrors the manual revisions made to the original Supplementary Table 1 code to code/remove PHI from metadata before sharing.

## Expected order

Run upstream scripts first, then build the workbook:

```r
source("scripts/00_run_all.R")
# or, after selected upstream scripts have generated outputs:
source("scripts/11_build_supplementary_table1.R")
```

The table builder writes placeholders for missing optional source tables and records them in `missing_or_placeholder_tables_report.csv`, allowing reviewers to see which parts require optional data such as communication source tables or opt-in pseudobulk outputs.
